# ADR 0005: The name

Status: proposed, 2026-10-19. Needs a decision before the Marketplace listing; the repository and the docs use the working name `pr-guard` until then.

## Context

GitHub Marketplace requires that "the `name` in the action's metadata file must be unique" and "cannot match an existing action name published on GitHub Marketplace" ([publishing actions](https://docs.github.com/en/actions/sharing-automations/creating-actions/publishing-actions-in-github-marketplace)). The `uses:` path is `owner/repo`, so the repository name only has to be unique under the owner; the Marketplace `name` is global.

Checked on 2026-10-19, from the registries and the Marketplace search:

| Name | npm | GitHub Marketplace | Notes |
|---|---|---|---|
| `pr-guard` | free (404) | no exact match | But at least seven actions carry "PR Guard" or "PRGuard" in their names (PRGuard by kzw-ai, PRGuard by sudhanshutech, EON PR Guard, Agent PR Guard, Secure PR Guard, AI Slop PR Guard, PR Size Guard), all AI code review or PR quality gates; `prguard` exists on npm (kwailapt, 2026-04-30); 72 repositories named `prguard`; `pr-guardian` has 170 stars |
| `migration-guard` | free | **taken**: "Migration Guard" by stef41, a database migration safety checker (12 PostgreSQL rules); also "PostgreSQL Migration Guard" and "DB Guard" | Direct competitors own the name |
| `safe-migrate` | free | **taken**: "safe-migrate" by dsecurity49, 29 stars, PostgreSQL migration checks | Direct competitor |
| `schema-guard` | **taken** (runtime type guards, unrelated) | no exact match | Confusing |

## Decision (proposed)

Keep `pr-guard` as the repository and working name through the pilots. It is free on npm, has no exact Marketplace match, and says what the product is: a guard on pull requests, which is also what it will be when the Java and Go packs ship. The crowd of "PR Guard" AI reviewers is a discoverability cost, not a conflict.

Before the Marketplace listing, choose between:

1. **`pr-guard` with a qualifying Marketplace name** such as "pr-guard: migration and production-safety checks". Low effort; discoverability relies on the docs and the sister repositories.
2. **A new coined name** that is free on npm, GitHub and the Marketplace and is not "guard"-based, checked at decision time. Better long-term identity; costs a rename across six repositories' links.

`ddl-guard` and `pg-guard` are reserved as fallbacks for the PostgreSQL pack name if the product name changes; they are not product names because the product is not PostgreSQL-only.

## Consequences

- Every document uses `pr-guard` and the path `rafapeixer/pr-guard`; a rename is a search and replace plus new ADR.
- Publishing to npm (`pr-guard` for the CLI) should happen with the first release to hold the name.
- The Marketplace listing waits for the pilots' end, which is when the name decision is due.
